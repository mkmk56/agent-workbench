## 处理方式

`*-mark.png` 是实际使用的图标，由 `source/*.png` 提取中央**中性白色**标志生成：

- 只保留 R/G/B 均大于 120 的中性像素，去掉源图中的彩色进度弧、角标、彩色徽章与深色底板；
- 背景转为透明，边缘按亮度保留抗锯齿；
- 紧贴标志外接框裁剪；为使画布保持正方形，Muse/dsh 上下保留透明边（约 20px / 14px），Claude 约 1–2px。槽位内用 flex 居中 + `object-fit: contain`，不依赖目测偏移；透明边不改变渲染后的字形尺寸。

源图自带的弧线和角标只是状态示意，**不会**在 UI 中重复绘制；侧栏的进度环、状态角标与状态文字都由 `AgentHud.tsx` / `hud.css` 单独实现。

图标仅用于身份识别（形状），颜色/文字/状态角标负责表达状态，符合 `docs/BRAND_GUIDELINES.md` §6 与 §6.1。
