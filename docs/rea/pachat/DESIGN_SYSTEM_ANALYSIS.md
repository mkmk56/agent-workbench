# Pachat 设计系统分析

> 依据：官方文档与首页文本（2026-11-18）。精确色值无法从文本获取，见 UNKNOWN_AND_ASSUMPTIONS.md。

## 1. 身份表达：不用气泡颜色

- Pachat **不用每 agent 气泡颜色**区分身份。
- 身份表达三件套：**平台 logo 头像 + 名字 + 标签**（"Your agent" / "Human"）。
- 结论：我方的气泡身份色是**自主设计**，不是抄 Pachat；方向需自洽，
  不必以 Pachat 为准。

## 2. 可借鉴的设计点

| 点 | Pachat 做法 | 我方应用 |
|---|---|---|
| 身份色强度 | 只用作气泡底色 tint（4–6%）/ 细左线 + 名字颜色 | 与用户已定方向一致（克制低饱和）；预览已发待确认 |
| 颜色映射 | 存在 Agent 身份表，从克制调色板自动分配 | 与 Profile Card 一起做，颜色映射进身份表 |
| @ 高亮 | 用被 @ Agent 的同一颜色 | Phase 2 消息渲染 |
| 引用块 | 用被引用 Agent 的颜色 | Phase 2 消息渲染 |
| 结论卡片 | 首页 Agreed / Not yet 的 decision widget 样式 | 是否为真实功能未核实；按"结论卡片式交互"借鉴，不照抄 |

## 3. 我方已定方向（用户 2026-11-18 确认）

- 仅聊天气泡使用克制低饱和身份色；其余界面（侧边栏、HUD、按钮）继续无身份色。
- Muse = 墨色中性（无色相）；Claude = 哑光陶土；dsh = 哑光石板蓝；用户 = 中性灰。
- 预览已发给用户待挑；定稿后写入 token 层（Muse 亲自写，dsh 交叉审）。

## 4. 不借鉴的

- 中央服务器托管的群聊视觉（与本地工作台的产品形态不同）。
- 公开社区的发现页视觉（Phase 5 暂缓）。
