设计约束

  • 信息密度优先：表格行高 44px，日志 13px 等宽；页面不使用大卡片堆叠，也不用统计仪表盘填充空间。
  • 状态必须同时有颜色、圆点和文本；不使用纯颜色表达成功 / 失败 / 运行中。
  • 控件高度 32px（小号 28px），圆角只用 4 / 8 / 12px；不使用胶囊按钮、胶囊标签。
  • 禁止紫蓝渐变、辉光、玻璃拟态、机器人 / 大脑图形、emoji 图标与无意义装饰。
  • 字体只使用系统 Segoe UI Variable Text / Microsoft YaHei UI；代码使用 Cascadia Code；不加载外部字体。
  • 焦点可见：2px 信号橙描边，偏移 2px；深色模式改用浅橙。

Astryx 组件对应

  • AppShell / TopNav / SideNav → 顶栏、左侧导航、主内容区。
  • Section、Table、Badge、StatusDot、Button、Field、Selector、Banner、ProgressBar、MetadataList → 各屏对应区域。
  • Astryx 没有现成日志查看器；任务详情中的日志流按 Astryx token 自定义，正式工程使用虚拟列表。
  • 组件默认值需覆盖：Badge 圆角 4px、橙色按钮文字用 Ink、字体改为系统字体、蓝色信息色映射为中性灰。

资源与打开方式

直接双击 index.html 即可查看；无需构建，不加载外部资源。主题切换会写入 localStorage。 品牌 SVG 是从 design/brand-icon @ 62957d8 复制的预览副本； 正式 GUI 工程应合并或复制 assets/branding/，不要重画图标或字标。

设计说明见 docs/UI_REDESIGN_ASTRYX.md；本目录只用于设计确认，不代表正式 GUI 工程结构。
